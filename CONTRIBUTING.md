# Contributing Guidelines

Thank you for considering contributing to the LifePulse Real-Time Blood Bank System!

## How to Contribute

1. Fork the repository.
2. Create a new feature branch: `git checkout -b feature/amazing-feature`.
3. Ensure all automated tests pass: `node backend/test_suite.js`.
4. Commit your changes following conventional commits: `git commit -m 'feat: add amazing feature'`.
5. Push to your branch: `git push origin feature/amazing-feature`.
6. Open a Pull Request.

## Code Standards
- Use clean, readable JavaScript and CSS.
- Ensure all database queries use parameterized SQL inputs (`?`).
- Never commit credentials, `.env` files, or database binaries.
