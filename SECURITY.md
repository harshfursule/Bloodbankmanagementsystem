# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of LifePulse seriously. If you discover a security vulnerability, please report it privately:

1. **Do NOT** open a public issue.
2. Email details of the vulnerability to the project maintainers.
3. Include steps to reproduce the issue and any relevant code snippets.

We will acknowledge your report within 48 hours and provide regular updates on remediation.
